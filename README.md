# DEEMO — 웹 기반 하이퍼 FPS

## 게임 개요

Three.js, TypeScript, Vite로 제작한 PC 브라우저용 1인칭 하이퍼 FPS 게임입니다. 이동과 사격뿐 아니라 그래플링 훅을 이용한 고속 기동을 중심으로 튜토리얼, 타임어택, 크리스탈 방어, 보스전을 차례로 진행합니다.

## 준비 및 실행

### 브라우저에서 바로 플레이

설치 없이 아래 링크를 열면 브라우저에서 바로 플레이할 수 있습니다.

https://arigery.github.io/FPS_AI_Game/

Chrome 기반의 최신 PC 브라우저 사용을 권장합니다. 진행 기록, 스테이지 해금 상태와 점수는 각 사용자의 브라우저 로컬 저장소에 저장되며 다른 사용자와 공유되지 않습니다.

### 로컬 환경에서 실행

1. [GitHub 저장소](https://github.com/Arigery/FPS_AI_Game)에서 `Code` → `Download ZIP`을 선택하거나 Git으로 저장소를 복제합니다.
2. ZIP으로 받았다면 원하는 위치에 압축을 풉니다.
3. [Node.js](https://nodejs.org/) 20 이상 버전(LTS 권장)을 설치합니다.
4. PowerShell을 열어 **본인이 프로젝트를 저장한 폴더**로 이동합니다.
5. 의존성을 설치하고 개발 서버를 실행합니다.

```powershell
cd "본인이 저장한 프로젝트 폴더 경로"
npm.cmd install
npm.cmd run dev
```

터미널에 표시되는 주소(기본값 `http://localhost:5173`)를 Chrome에서 엽니다. 개발 서버는 PowerShell에서 `Ctrl+C`를 눌러 종료할 수 있습니다.

Git으로 저장소를 복제하려면 다음 명령을 사용할 수 있습니다.

```powershell
git clone https://github.com/Arigery/FPS_AI_Game.git
cd FPS_AI_Game
npm.cmd install
npm.cmd run dev
```

## 간단한 조작 설명

- `W` / `A` / `S` / `D`: 이동
- 마우스 이동: 시점 조작
- `Space`: 점프 / 그래플링 이동 중 훅 해제
- `Left Shift`: 그래플링 훅 발사
- 마우스 우클릭: 줌
- 마우스 좌클릭: 줌 상태에서 사격 / 비줌 근거리에서 근접 공격
- `R`: 재장전
- `P`: 현재 스테이지 시작 위치로 리스폰
- `Esc`: 스토리 건너뛰기 / 게임 중 일시정지 및 포인터 잠금 해제

## 게임 진행 설명

- 처음에는 튜토리얼만 플레이할 수 있습니다.
- 튜토리얼 클리어 시 Stage 2가 해금됩니다.
- Stage 2 클리어 시 Stage 3가 해금됩니다.
- Stage 3 클리어 시 최종 훈련인 Stage 4가 해금됩니다.
- 튜토리얼에서는 이동, 점프, 근접 공격, 줌 사격과 그래플링 사용법을 순서대로 익힙니다.
- 스테이지 시작과 종료 시 하단 대화창으로 간단한 스토리가 진행됩니다. `Space`로 문장을 완성하거나 다음 대사로 넘어갈 수 있고, `Esc`로 대화를 건너뛸 수 있습니다.
- 해금 상태, 옵션과 Stage 2·Stage 3의 상위 기록은 브라우저 로컬 저장소에 보관됩니다.
- 다른 브라우저나 다른 기기에서는 별도의 기록으로 시작하며, 브라우저 데이터를 삭제하면 저장 기록도 초기화될 수 있습니다.

## Stage 2 규칙 — 그래플링 타임어택

- 고정된 미래 도시 코스를 그래플링으로 이동해 결승 그린존에 도달하는 타임어택 스테이지입니다.
- 맵에 배치된 과녁 20개 중 **10개 이상을 처치해야** 결승 그린존에서 클리어할 수 있습니다.
- 10개 미만으로 처치한 상태에서 결승점에 도달하면 필요한 처치 수가 화면에 안내됩니다.
- 사격, 근접 공격, 그래플링 직접 충돌 처치는 각각 5점입니다.
- 결승 도달 시간에 따라 시간 점수가 추가됩니다.
- 낙사하거나 `P`를 누르면 시작 지점으로 돌아가며, 해당 도전의 점수와 통계는 유지됩니다.
- 결과 화면에서 점수, 클리어 시간, 처치 수와 명중률을 확인할 수 있습니다.

## Stage 3 규칙 — 크리스탈 방어

- 제한 시간 180초 동안 6개의 공성 지점에 배치된 크리스탈을 방어합니다.
- 6개의 크리스탈은 하나의 체력 200을 공유합니다.
- 플레이어 최대 체력은 100이며, 일정 시간 피해를 받지 않으면 자동으로 회복합니다.
- 적 부대는 공성병 1명과 호위병 2명으로 구성됩니다.
- 공성병은 목표 크리스탈을 공격하므로 우선적으로 처치해야 합니다.
- 호위병은 공성병을 보호하고 플레이어를 공격합니다. 공성병이 쓰러진 뒤에도 살아남은 호위병은 플레이어를 계속 추격합니다.
- 다음 적 출현 위치는 5~8초 전에 붉은 화면 테두리 표식으로 안내됩니다. 표식은 해당 공성병을 처치할 때까지 유지됩니다.
- 시작 후 100초까지는 한 번에 한 부대가 등장하고, 이후에는 일정 확률로 서로 다른 위치에 최대 두 부대가 등장합니다.
- 180초가 끝날 때 플레이어와 공유 크리스탈의 체력이 모두 남아 있으면 클리어합니다.
- 플레이어 또는 공유 크리스탈의 체력이 0이 되면 즉시 실패합니다.
- 점수는 공성병 처치, 호위병 처치와 남은 크리스탈 체력을 기준으로 계산됩니다.

## Stage 4 규칙 — 최종 보스전

- 원형 아레나에서 그래플링 구조물을 이용해 거대 전쟁 기계의 공격을 피하며 약점을 파괴합니다.
- 플레이어 최대 체력은 100이며 체력 회복 방식은 Stage 3와 같습니다.
- 약점은 `양쪽 어깨 보호대 → 이마 코어 → 양쪽 무릎 관절` 순서로 활성화됩니다.
- 양쪽 어깨 보호대는 각각 3회, 이마 코어는 4회, 양쪽 무릎 관절은 각각 4회 명중시키면 파괴됩니다.
- 보스는 유도 미사일, 레일건, 팔 내려찍기와 지면 충격파를 사용합니다.
- 붉게 표시되는 공격 예고 범위에서 벗어나거나 그래플링으로 공중 이동해 공격을 피해야 합니다.
- 전투 후반에는 서로 양립할 수 없는 일부 조합을 제외하고 공격 패턴이 동시에 두 개씩 진행될 수 있습니다.
- 모든 약점을 파괴해 보스를 가동 중지시키면 최종 훈련을 클리어합니다.
- Stage 4 결과 화면의 `다음 스테이지로` 버튼을 누르면 게임 완료 메시지가 표시됩니다.

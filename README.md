# Hyper FPS 프로토타입 — Phase 1 + Stage 2 + Stage 3

Three.js, TypeScript, Vite 기반의 PC 브라우저용 하이퍼 FPS 프로토타입입니다. 튜토리얼, 고속 갈고리 타임어택 Stage 2, 기동형 공성 방어 Stage 3가 구현되어 있습니다.

## 사운드

- 메뉴 및 UI 버튼 클릭음과 `Esc` 일시정지음
- 가벼운 SF 저격총 발사음과 적중음
- 갈고리 발사음과 부착음
- 플레이어 피격음
- 재장전 중 반복되는 기계 작동음
- 튜토리얼 체크박스 성공음
- 작은 발소리와 착지 충격음
- 낙사, Stage 3 플레이어 사망 및 크리스탈 파괴 시 재생되는 공통 실패 효과음
- 튜토리얼·Stage 2·Stage 3에서 공통 재생되는 전투 BGM(메뉴 및 일시정지에서는 정지)
- 전투·UI 효과음은 기존 대비 약 1.7배 강화하고 BGM은 별도 저음량 버스로 분리
- 옵션의 1~10단계 소리 크기와 연동

## 준비 및 실행

1. Node.js 20 이상(LTS 권장)을 설치합니다.
2. PowerShell을 열고 **본인이 프로젝트를 저장한 폴더**로 이동합니다.
3. 의존성을 설치하고 개발 서버를 실행합니다.

```powershell
cd "본인이 저장한 프로젝트 폴더 경로"
npm.cmd install
npm.cmd run dev
```

터미널에 표시되는 주소(기본 `http://localhost:5173`)를 Chrome에서 엽니다. 서버는 터미널에서 `Ctrl+C`로 종료합니다.

PowerShell 실행 정책 때문에 `npm.ps1` 오류가 발생하면 정책을 변경할 필요 없이 위 예시처럼 `npm` 대신 `npm.cmd`를 사용하면 됩니다.

## 게임 진행

- 첫 실행에서는 `게임 시작` → `튜토리얼`을 완료해야 Stage 2와 Stage 3가 해금됩니다.
- 해금 상태와 스테이지 최고 점수는 브라우저 로컬 저장소에 기록됩니다.
- Stage 2는 과녁 처치 수와 관계없이 그린존에 진입하면 종료됩니다.
- Stage 3는 여러 공성 지점 사이를 이동하며 크리스탈을 3분 동안 방어합니다.

## 조작

- `W/A/S/D`: 이동
- 마우스: 시점
- `Space`: 점프 / 갈고리 이동 중 해제
- `Left Shift`: 갈고리 발사
- `Right Mouse`: 줌
- `Left Mouse`: 줌 상태에서 사격, 비줌 근거리에서 근접 공격
- `R`: 재장전
- `P`: 현재 스테이지 시작 위치로 리스폰
- `Esc`: 일시정지 / 포인터 잠금 해제

## Stage 2 규칙

- 고정된 도심 코스에서 과녁을 선택적으로 처치하며 결승 그린존까지 이동합니다.
- 사격, 근접 공격, 갈고리 직접 충돌 처치는 모두 5점입니다.
- 결승 도달 시간에 따라 시간 점수가 추가됩니다.
- 낙사 또는 `P` 입력 시 시작 지점으로 돌아가며 점수와 통계는 유지됩니다.

## Stage 3 규칙

- 제한 시간: 정확히 180초
- 맵 크기: X 60m × Z 200m, 최대 높이 Y 25m
- 간격을 넓힌 6개 공성 지점에 소형 크리스탈이 배치되며 하나의 200 HP를 공유합니다. 북부·남부 크리스탈 2개는 건물 옥상에 있습니다.
- 플레이어 최대 HP: 100
- 고정 공성 지점: 북쪽 3개, 남쪽 3개
- 공성 파티: 공성병 1명 + 호위병 2명
- 공성 파티는 이번에 선택된 목표 크리스탈 바로 옆에서 생성됩니다.
- 호위병 공격 사거리: 30m(실제 시야가 확보된 경우에만 사격)
- 공성병 처치 후 호위병의 추격 이동 속도는 6.5m/s입니다.
- 크리스탈은 이동·갈고리 충돌은 유지하지만 총알을 막지 않으므로 뒤쪽 적을 사격할 수 있습니다.
- 공성병은 지점 도착 후 4~6초 동안 전개하고 크리스탈 원거리 공격을 시작합니다.
- 공성병은 사격, 근접 공격, 갈고리 직접 충돌 중 어떤 공격이든 한 번 맞으면 처치됩니다.
- 공성병 처치 시 해당 파티의 크리스탈 공격은 영구 중단됩니다.
- 살아남은 호위병은 사라지지 않고 플레이어를 계속 추격합니다.
- 다음 공성 지점은 활성화 3~5초 전에 HUD와 장애물을 무시하는 화면 테두리 마커로 경고됩니다.
- 활성화된 붉은 표식은 해당 공성병이 처치될 때까지 유지됩니다.
- 초반에는 공성 지점 1개, 후반에는 최대 2개가 동시에 활성화될 수 있습니다.
- 180초 종료 시 플레이어와 크리스탈 HP가 남아 있으면 클리어합니다.
- 플레이어 또는 크리스탈 HP가 0이 되면 즉시 실패합니다.
- `Esc` 일시정지 중에는 타이머와 AI가 함께 멈춥니다.

## 배포 빌드

```powershell
npm.cmd run build
npm.cmd run preview
```

빌드 결과는 `dist` 폴더에 생성됩니다.

## 문제 해결

- `node` 또는 `npm`을 찾지 못하면 Node.js 설치 후 PowerShell을 새로 엽니다.
- `npm.ps1` 실행 정책 오류가 나면 `npm.cmd` 명령을 사용합니다.
- 경로에 공백이 있으면 `cd "프로젝트 폴더 경로"`처럼 큰따옴표로 감쌉니다.
- 포트가 사용 중이면 Vite가 표시하는 대체 주소를 사용하거나 `npm.cmd run dev -- --port 5174`로 실행합니다.
- 검은 화면이 보이면 Chrome 개발자 도구의 Console과 WebGL2 하드웨어 가속 상태를 확인합니다.
